## 1b. Как выпустить токены

**GitHub (публикация из админки):** github.com → аватар → Settings → в самом низу Developer settings →
Personal access tokens → **Fine-grained tokens** → Generate new token. Repository access: **Only select
repositories** → `neon-graphics`. Permissions → Repository permissions → **Contents: Read and write**
(Metadata: Read появится сама). Значение вида `github_pat_…` показывается один раз — сразу копировать.
Записать дату истечения: когда токен протухнет, публикация начнёт выдавать ошибку.

**Telegram (заявки):** в Telegram найти **@BotFather** → `/newbot` → получить токен вида `8123456789:AAH…`.
Затем узнать chat_id: написать боту (или добавить его в группу и написать там), открыть в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`. **У группы id с минусом** —
минус копировать обязательно.

**Почта Яндекса (заявки):** id.yandex.ru → Безопасность → включить двухфакторную аутентификацию →
**Пароли приложений** → тип «Почта» → получить 16-символьный пароль (это `SMTP_PASSWORD`, не основной
пароль от почты). В настройках почты должен быть включён доступ по IMAP/SMTP.
Хост `smtp.yandex.ru`, порт `465`, `SMTP_USER` и `SMTP_FROM` — полный адрес ящика.

**Как вбивать в Vercel:** проект → Settings → Environment Variables → Key + Value, отметить окружения
**Production** и **Preview** → Save. Без кавычек, без пробелов по краям. После добавления переменных
нужен редеплой: Deployments → последний деплой → ⋯ → Redeploy.

Проверить результат: админка → **Проверка интеграций** — там статус каждого канала и кнопка тестовой
заявки.
